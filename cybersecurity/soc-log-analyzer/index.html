Detection logic and safe-use notes

Rules in this learning demo flag five or more failed logins for the same username and source IP, five or more distinct usernames with failed logins from one source IP, and a successful login after at least three failures for the same username and source within 30 minutes.

These are simple heuristics, not proof of compromise. Real SOC investigations require environment context, validated telemetry, tuning, and a documented response process. This demo only analyzes data selected by the user in this browser tab; it does not transmit or persist logs.
